## Windows

1. Download `SmarterHumans-Setup-<version>-x64.exe` from the latest release.
2. Run it. No administrator rights are needed; the app installs for your user only.
3. The app checks for updates by itself. When a new build is out, an update button appears at the
   bottom of the sidebar.

⚠️ **To update, never uninstall first.** The uninstaller removes your data on this PC (cards,
notes, library). Run the new `Setup.exe` over the old install, or use the update button in the app:
both keep your data.

Needs Windows 10 version 1809 or later, x64, 8 GB of memory recommended.

## Android

1. Download `SmarterHumans-<version>.apk` from the latest release on the phone.
2. Open it. The first time, Android asks to allow installs from your browser or file manager:
   allow it, then go back and install.
3. The app checks for updates by itself. When a new build is out, a dot appears on the More tab;
   More → Update available installs it. The first update asks once to allow SmarterHumans to
   install apps.

Needs Android 11 or later on a 64-bit phone, 4 GB of memory recommended.

## macOS, iPhone and iPad

These builds go through TestFlight; ask the team for an invite.

## Checking a download

Each release lists the SHA-256 of its files. The apps check it themselves before installing an
update.
